🎄 Holiday Greeting Card Generator

Good Vibes, Well-Coded

A vibe-coded holiday greeting card generator exploring generative design, UX, and modern web tools.

Built as a fun, user-friendly creative coding experiment to explore interactive front-end development, motion, and component-based design.

🔗 Live Demo: https://virtual-holiday-greeting-card.vercel.app

⸻

✨ Features
	•	Custom greeting message generation
	•	Holiday scene selection with modular styling
	•	CSS-based animations and interactive motion
	•	Live Christmas countdown ticker (dynamic date logic)
	•	Shareable link-based output
	•	PNG and JPG export options
	•	Component-based CSS system for scenes
	•	Fully deployed, browser-based web application

⸻

🧠 Project Intent

This project was intentionally designed as a low-pressure, creative experiment to explore vibe coding, building quickly and intuitively while still maintaining structure, polish, and thoughtful UX.

AI-assisted tools were used as collaborators to accelerate iteration and problem-solving, while all design decisions, logic, and implementation were directed and refined by hand.

⸻

🛠 Tools & Technologies
	•	Modern JavaScript front-end framework
	•	HTML, CSS (component-based architecture)
	•	Claude Code for AI-assisted development
	•	GitHub for version control
	•	Vercel for deployment and hosting

🎯 Skills Demonstrated
